# Odin Landing Page

A landing page built from a provided design for The Odin Project's Foundations course.

**Live site:** [GitHub Pages](https://marka-quipit.github.io/odin-landing-page/)

**Assignment:** [Landing Page](https://www.theodinproject.com/lessons/foundations-landing-page)

## What's in it

- Header with a logo and three nav links
- Hero section with a heading, subtext, and a "Sign up" button
- "Some random information" section with four image + caption blocks
- Quote section attributed to Thor, God of Thunder
- Call-to-action section with a second "Sign up" button
- Footer with copyright

I kept the dummy content from the design. The info section uses one stock photo for all four image slots.

## What I practiced

- I wrote the HTML file first in a semantic format, then modified it later for CSS styling.
- I also practiced atomic commits, one per change.
- I used what I learned in the flexbox section, with major thanks to [Josh Comeau's interactive guide to flexbox](https://www.joshwcomeau.com/css/interactive-guide-to-flexbox/). I used flex in my own way, in a way that makes sense to me, and it deepened my knowledge of flex in general.
- Some of the techniques I used are advanced, and I'm still practicing them in this project. I still have to go back to previous lessons or sites.

## Scope

HTML and CSS only. Not responsive, per the assignment.

## What was hard

- Flex in general
- Image attributes
- Deciding which values to use and the order they go in

## My thoughts on this project

I think I did pretty well following the desired outcome. I did try searching the web to make it responsive, but I currently lack the knowledge to use flex for that. What I've used in other projects is grid. I plan to transition from using grid alone to a hybrid of grid and flex, because I've seen the pros and cons of each.
